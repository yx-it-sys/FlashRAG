# Intervention Analyses

This directory stores the prose interpretation notes for the intervention figures.

## Files

- `bar_charts.md`: backbone-level trajectory quality and final-answer analysis.
- `mechanism.md`: mechanism analysis of utility collapse, iteration changes, and task-specific effects.
- `entity_ambiguity_frequency.md`: ambiguity frequency summary across models.
- `sample_count.md`: sample count and composition summary.
- `trajectory_decay.md`: trajectory-level step-score decay with zero-padding after termination.
