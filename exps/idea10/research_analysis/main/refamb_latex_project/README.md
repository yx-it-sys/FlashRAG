# RefAmb LaTeX Project

This directory contains the paper content and figure assets for the RefAmb manuscript.

## Included

- `main.tex`: main manuscript source
- `algorithm.tex`: algorithm block
- `appendix_prompt_engineering.tex`: appendix content
- `paper_figs/`: figures intended for the paper
- `figs/`, `table/`, `raw_data/`: figure-generation assets, tables, and supporting data
- `analysis/`: interpretation notes corresponding to the figures

## Not included

Template-related files are intentionally left out here and will be handled separately.
